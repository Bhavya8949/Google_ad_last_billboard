# Google Ad - Last Billboard

Google Ads API integration for the Last Billboard centralized advertising platform.

## Features

- Google Ads API authentication
- Service account authentication
- Manager-to-client account access
- Campaign budget creation
- Campaign creation and management
- Ad group creation and management
- Keyword creation
- Responsive Display Ad creation
- Display image validation
- Campaign, Ad Group, and Ad status management
- Pause and enable operations
- Google Ads policy approval checks
- Ad review status checks
